# BBS-Cubed 1.21.11 适配计划（3.6.8 重整版）

> 盘点基线：`mod_version=3.6.8`，`HEAD=a47ebc9`，分支 `3.5`，盘点日期 2026-11-11。
> 本文只做现状盘点与计划，**未修改任何代码、构建脚本或 README**。
> 对照版本：1.20.1 主发布版（单 jar 覆盖 1.20.1–1.20.4）。

## 0. 结论摘要

1. **1.21.11 当前不能构建**。`build12111` 在 `ModelFormRendererLimbPickMixin.java:26` 因 1.21.11 BBS 已移除 `BBSRendering.isIrisWorldShadersEnabled()` 而失败，只有 1 个编译错误；`build1201` 正常。恢复构建是 P0，约 0.5 人日。
2. **渲染底座已经打通**。3.6.6–3.6.8 已完成 `RenderPipeline` 分级着色、轮廓线主体、物品喷射、流体形态、立方模型 CPU UV、拾取修正；这些不应再按“未移植”重复开发。
3. **剩余缺口集中在“逐骨骼/非主模型格式”和“屏幕空间/UI/影片”**：逐骨骼 PBR、骨骼贴图、肢体剔除、装备变换、挤出/公告板 UV、拖尾与原版粒子着色、屏幕后处理、热键栏 HUD、Particle Plus、影片世界曲线/回放时间、约 20 个编辑器 UI 功能。
4. **按当前排除清单，1.21.11 排除 82 个文件 / 13,809 行**；共享源码共 516 文件 / 64,050 行，排除行数约占 21.6%，与 README 的“约 20% 未适配”口径一致。但其中一部分是 1.20 专用或已被新路径取代，**实际功能缺口小于行数比例**。
5. 剩余工作拆为 **WP0–WP6**，合计约 **21–31 人日**；关键路径是 WP1（模型逐骨骼特性）→ WP4（编辑器 UI）。AAA、IRLite、VFX、IMBlocker 受外部 1.21.11 构建阻塞，Iris 受上游内部 API 阻塞，均不应计入可独立完成的工作量。

**状态图例**：✅ 已可用；🟡 部分可用；❌ 未适配；⛔ 外部阻塞/不可独立完成。

### 1.3 失败根因

`ModelFormRendererLimbPickMixin.java:23-26` 的 `@Redirect` 目标与函数体都依赖 1.20.1 的 API：

```java
@Redirect(method = "render3D", at = @At(
    value = "INVOKE",
    target = "Lmchorse/bbs_mod/client/BBSRendering;isIrisWorldShadersEnabled()Z"))
private boolean bbspp$limbPickVanillaShader()
{
    return LimbPickMode.held() || BBSRendering.isIrisWorldShadersEnabled();
}
```

- 1.20.1 BBS：`libs/bbs-fs-2.6-1.20.1/.../BBSRendering.java:724` 仍有 `isIrisWorldShadersEnabled()`；1.20.1 `ModelFormRenderer.render3D` 用它挑选主着色器。
- 1.21.11 BBS：`BBSRendering.java:1030` 只有 `isIrisShadersEnabled()`，另有 `isIrisWorldForms()`（`:1316`），**没有** `isIrisWorldShadersEnabled()`。
- 1.21.11 `ModelFormRenderer.render3D`（`:881`）已删除 1.20.1 的 program 切换分支，并在 `:937-944` 注明“program swap 与 deferred queue 的配合在这一支已不存在，dance 被移除”。因此这个 mixin 在 1.21.11 上既没有目标调用，也没有可执行的语义，属于 **1.20.x 专用**。

### 1.4 修复方案（P0，先在计划中定稿）

| 方案 | 做法 | 优点 | 风险 | 结论 |
|---|---|---|---|---|
| A（推荐） | 把 `mixin/client/ModelFormRendererLimbPickMixin.java` 加入 1.21.11 excludes，并修正 mixin 配置清理正则 | 与现有 82 文件排除机制一致；1.20.1 不受影响 | 需同时修 `build.gradle:182`，否则残留 `"client.ModelFormRendererLimbPickMixin"` | ✅ |
| B | 把该 mixin 移到 `src/main/java-1.20.x` | 源码按版本天然隔离 | 1.21.11 的 mixin JSON 仍引用不存在的类，仍需按目标删条目；且要改共享源码布局 | 不优先 |
| C | 改写函数体不再调用缺失方法 | 可编译 | 1.21.11 上 `@Redirect` 目标不存在，mixin 仍无法应用；保留死代码 | ❌ |

**必须注意的配置清洗 bug**：`build.gradle:170-196` 的 `doLast` 只按“简单类名”匹配 mixin 条目：

```groovy
def simpleName = excl.substring(excl.lastIndexOf('/') + 1).replace(".java", "")
text = text.replaceAll("\"${simpleName}\",?\\s*", "")
```

而 `src/main/resources/bbsplusplus.mixins.json:144` 的条目是带包名的：

```json
"client.ModelFormRendererLimbPickMixin",
```

所以只加 excludes 不会删掉该条目。应把正则改为允许可选包前缀（例如 `"([\\w$]+\\.)*${simpleName}"`），或在 1.21.11 分支单独移除该条目。**不能无条件删除该条目**，1.20.1 仍需要它。

修复后的预期：1.21.11 排除 **83 文件 / 13,837 行**；`build12111`、`build1201` 双绿；mixin 配置清洗日志从 82 条相应增加，且无 dangling entry。

## 4. 差异根因与实现约束

### 4.1 1.20.1 → 1.21.11 关键 API 映射

| 1.20.1 用法 | 1.21.11 替代 | 影响 |
|---|---|---|
| `RenderSystem.enableBlend`/`Tessellator.getBuffer`/`BufferRenderer` | `RenderPipeline` + `RenderPass` + `GpuBuffer` | 所有立即模式绘制必须重写 |
| `ShaderProgram`/`GlUniform` | Pipeline 的 UBO + `RenderPass.setUniform(name, GpuBufferSlice)` | 旧 shader supplier、逐 uniform 写入全部失效 |
| `CubicVAORenderer`/`IModelVAO` | `ModelVAORenderer.render(...)` + CPU `ModelInstance.render` | 逐骨骼后处理要自己走 CPU 组遍历，不能“取消排除”旧 mixin |
| `Particle.red/green/blue/alpha` | `BillboardParticle` 同名字段 | `ParticleColorAccessor` 需改目标类 |
| `ParticleManager.renderParticles` | `ParticleManager.addToBatch` | 原版粒子重绘要接 batch，不是接 render |
| `WorldRenderEvents.END/LAST` + 旧 `WorldRenderContext` | `...rendering.v1.world.WorldRenderEvents.END_MAIN` 等；上下文只有 `matrices()/consumers()/commandQueue()` | 影片/HUD/曲线的世界钩子全部要改包名与取值方式 |
| 立即模式全屏 shader pass | `PostEffectPipeline`/`PostEffectProcessor` | 屏幕后处理应走原生框架，不要搬 `ColorGradeRenderer` |
| `MatrixStack` 用于 2D UI | `Matrix3x2fStack`；3D 预览用 `UIModelRenderer.createCameraStack()` | UI 迁移的主要编译错误来源 |
| `GameMode.getName/byName`、`sendCommand` | `getId/byId`、`sendChatCommand` | 机械替换，3 个文件 |
| `FabricBlockSettings` | `AbstractBlock.Settings.create()` | 发光方块两行替换 |
| `BBSRendering.isIrisWorldShadersEnabled()` | 无；只有 `isIrisShadersEnabled()` / `isIrisWorldForms()` | `ModelFormRendererLimbPickMixin` 失效（本次构建失败） |

### 4.2 已确认的渲染约束（写代码前必须遵守）

1. **`RenderLayer` 不能携带自定义 uniform**。模型 tint/whiten/glint 必须自建 `RenderPipeline` + std140 UBO + 手写 `RenderPass`；`GradePass` 已是可复用样板。
2. **半透明排序靠 `FormTranslucentQueue.DrawCommand`**。它是 `public abstract`、protected 构造、`add()` 公开；`flush()` 在帧末、任何 pass 之外，因此在 `draw()` 内开 pass 合法。新模型特性应继续走这条队列，不要退回直接 draw。
3. **模型唯一入口是 `ModelVAORenderer.render(ModelVAO, MatrixStack, r,g,b,a, light, overlay, cull)`**。`CubicVAORenderer` 已删除；逐骨骼特性要在 CPU 组遍历/提交层做，不能找旧类。
4. **`ModelInstance.render` 没有 shader supplier**：签名是 `(MatrixStack, Color, int, int, StencilMap, ShapeKeys, Function<String,Texture>)`。逐材质换纹理走 texture resolver；逐骨骼换纹理需要分组提交。
5. **`GradeSubmitHook` 只接受 `POSITION_COLOR_TEXTURE_OVERLAY_LIGHT_NORMAL` + `PASS_SINGLE`**。拖尾、公告板、挤出、流体、原版粒子都不在这个格式里，不能指望它自动覆盖。
6. **`applyToShader` 在 1.21.11 是 no-op**（`ModelUVTransformRuntime.java:55-61`）。UV 只能走 CPU 顶点改写；任何“再写一次 uniform”的方案都无效。
7. **原版粒子颜色字段在 `BillboardParticle`**，hook 点是 `addToBatch`；自建 `RenderLayer` 时 `RenderLayer.of` 包私有，需要 access widener。
8. **原生后处理**：`PostEffectPipeline`/`PostEffectProcessor` 可做多级 ping-pong；但 `isCustomSize()` 与 Iris 下有黑屏风险，必须做 fallback（`ScreenQuadPass`）。
9. **Iris 世界管线**：`GradePass` 已对 world 变体调用 `BBSRendering.mirrorIrisPipeline(...)`；但 shaderpack 可能覆盖 fragment 输出，glint/后处理在 Iris 下要单独验收。

### 8.2 功能冒烟（每条都要在 1.20.1 与 1.21.11 各跑一次）

1. 轮廓线：纯色、渐变、面颜色、深度写入、LabPBR 自发光（若已接）。
2. 模型 UV：立方、挤出、公告板、BOBJ 各一个形态，偏移/缩放正确。
3. tint/whiten：主模型、拖尾、公告板、挤出、流体、原版粒子。
4. glint：整模型、逐骨骼、Iris 开/关。
5. PBR/骨骼贴图/肢体剔除/装备变换。
6. 物品喷射：普通、IRLite 阴影（预期 warn 或已实现）。
7. 屏幕效果：颜色分级、暗角、扭曲、VHS、色差、径向模糊。
8. 热键栏 HUD：`/play`、录制、编辑器预览。
9. Particle Plus：创建、渲染、编辑、存读；Additive 材质。
10. AAA：无构建时 warn/不可编辑，不 NPE。
11. 影片：世界回放时间、shader 曲线、视频 seek、播放头偏移。
12. 自动旁观、发光方块。
13. 新变形 UI 开/关；原版分类菜单不被误删。
14. 曲线选择器、贴图 tween 编辑、动画预览、动作端点、姿势笔刷。
15. VFX 法杖、IMBlocker（有依赖时）。

### 8.3 兼容性

- 1.20.1 旧存档在 1.21.11 打开：普通形态、轮廓、喷射、流体、tween、PBR 数据不丢。
- AAA/Particle Plus 存档：只读打开不崩；1.21.11 重存前给出警告。
- 发光方块：1.21.11 缺失时退化为空气/未知，不导致区块加载失败。
