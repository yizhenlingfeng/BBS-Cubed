肉兔界面
BBS UI Rabbit

一个只换界面的 BBS 插件：启动台、影片库、伪装界面、模型 / 粒子 / 音频编辑器的主页，外加材质包预设。不改影片和素材文件，每块界面都能单独关掉，关掉就是 BBS 原来的样子。

版本 1.0.12026 年 11 月只需要 BBS FS 2.7
00

安装与开关

放进 mods 文件夹就能用，不需要其他前置。

需要版本
Minecraft1.20.1
Fabric Loader0.15 或更新
Fabric API1.20.1 对应版本
BBS FS2.7
Java17 或更新

安装

  1. 把 bbs-ui-rabbit-1.0.1+bbsfs2.7.jar 放进这个版本的 mods 文件夹。
  2. 启动游戏，直接看到启动台就说明装好了。
  3. 想关掉某块界面：BBS 仪表盘 → 设置 → 肉兔界面（全部开关见附录 A）。
和 BBS++ 一起装可以。只是 BBS++ 自己也带一套旧版的影片库和伪装界面：请在 BBS++ 的设置（BBS增强）里让「全新影片库界面」「全新伪装界面布局」保持关闭（默认就是关的），否则两套界面会抢着显示。
卸载把 jar 从 mods 里删掉即可，界面回到 BBS 原样，影片和素材不受影响。
01

启动台

打开游戏就是启动台，代替原版的标题界面、选择世界和多人游戏。退出世界后也回到这里。

  1. 1导航：单人游戏（全部 / 最近游玩 / 收藏 / 有影片的）、你的标签、多人游戏（服务器 / 局域网 / Realms）。
  2. 2搜索、排序、新建世界：世界名、标签、影片名都能搜；右边的小太阳切换深浅色。
  3. 3世界卡片：图是这个世界最新影片的封面，角标是影片数量、游戏模式、标签。单击选中，双击进入。
  4. 4锁定封面：锁住后以后有新影片也不换图。右下角「换封面」可选影片封面或图片。
  5. 5世界信息与标签：「＋ 添加标签」输入后回车，点 × 删除。点世界名可以改名或起别名。
  6. 6这个世界的影片：鼠标停在小图上弹出影片卡，轮播预览帧，显示时长和修改时间。
  7. 7进入世界，下面是编辑、备份、文件夹、更多（重新创建、删除）。
  8. 8小文绪：装饰动画，会看鼠标、对你的操作有反应，闲着会睡着。底下一排是原版按钮（模组、选项、语言、无障碍、退出）。

1.1单人游戏

进入、编辑、整理世界

操作
  • 进世界：单击卡片选中，右侧出详情；双击或 Enter 进入。
  • 编辑：打开原版的编辑世界界面（重命名、备份、优化、导出生成设置都在）。
  • 改名和别名：点详情里的世界名，选「改名」（改存档里的名字）或「起别名」（只在启动台显示，不动存档，随时能清除）。
  • 标签：侧栏的标签右键可以给所有世界一起改名，或从所有世界删除。超平坦世界自动带「超平坦」标签。
  • 封面：默认用最新影片的封面，没有影片就用世界图标。右键大图或点「换封面」：用某部影片的封面、选择图片（默认打开截图文件夹，F2 截的图直接能用）、恢复默认。
  • 新建世界：原版创建界面，或者模板「超平坦拍片地」（超平坦、创造、开作弊、关昼夜 / 天气 / 生物生成）。
按键
↑↓←→ 选择，Enter 进入，Ctrl+F 搜索，Delete 删除，F5 刷新。
何时用
存档多的时候用标签分项目（比如「第三集」「测试用」），用「有影片的」快速找到拍过东西的世界，用锁定封面让常用世界一眼认出来。
怎么调
设置 → 肉兔界面 →「启动台大小」默认 1.3。屏幕小、字太大就调到 1.0 左右，2K / 4K 屏可以调到 1.6 以上。

1.2多人游戏

服务器与局域网

操作
  • 服务器列表和原版共用同一个 servers.dat，打开时自动 Ping。
  • 地址栏输入地址按回车 = 直接连接。添加 / 编辑用原版界面；「⋯」里可以上移、下移、复制地址、删除。
  • 同一局域网里开放的世界会自动出现在「局域网」里。
启动台出错会自动关掉并换回原版标题界面，这次游戏里不再出现。遇到时请把 logs/latest.log 发给作者。
02

影片库

影片面板没有打开影片时，看到的就是影片库：文件夹、收藏、搜索、封面、悬停预览、颜色标签和影片详情。

  1. 1浏览：全部影片、最近使用、收藏。
  2. 2颜色标签筛选：点一个色点只看这个颜色，再点一次显示全部。
  3. 3文件夹：＋ 新建；右键新建子文件夹、重命名、删除（只能删空文件夹）。
  4. 4搜索与排序：搜名称、路径、描述；按最近修改、名称、创建时间、时长、最近打开排序。
  5. 5新建影片；下面一排是列表 / 网格切换和影片体检（感叹号）。
  6. 6影片卡：封面、时长、颜色标签。鼠标左右移动逐帧预览，停住自动轮播。
  7. 7详情：颜色标签、时长、修改 / 创建时间、回放数、摄像机剪辑数、编辑用时、描述。
  8. 8镜头时间轴：这部影片的摄像机剪辑一览。
  9. 9打开影片，下面是重命名、复制、更多。

2.1影片库主页

找影片、开影片、整理影片

入口
仪表盘 → 影片面板，没有打开影片的标签页（或新开一个空标签页）。
操作
  • 单击选中看详情，双击或 Enter 打开。
  • 默认是网格视图；右上角可以换成列表视图（见图），会记住你的选择。
  • 影片右键：打开、重命名（F2）、复制、移动到…、删除（Delete，不可撤销）、收藏、封面…、颜色标签、打开所在文件夹、在数据管理器中显示。
  • 点星标收藏；Ctrl+F 搜索，Ctrl+N 新建。
  • 联机时（大家都装了 BBS Together），别人正打开的影片上会写「某某 正在编辑」。
何时用
一个世界里影片超过十几部时：按集数或场次建文件夹，在描述里写这一镜的内容，搜索时能搜到。

2.2封面、悬停预览、颜色标签

每部影片自动有封面和 8 张预览帧

自动
在编辑器里打开影片、用影片相机看一遍，就会自动截封面（影片 30% 处）和 8 张分布在全片的预览帧。黑场不会当封面。
手动
  • 影片编辑器里右键录制按钮 →「把当前画面设为影片封面」：截的是不带编辑器界面的画面，会闪一下白光。
  • 把图片文件直接拖到影片库里的影片上；或右键影片 → 封面… → 选择图片作为封面…
  • 手动设的封面不会被自动覆盖；想回到自动封面，选「恢复自动封面」。
颜色标签
右键影片 →「颜色标签」：红、橙、黄、绿、青、蓝、紫、粉。卡片会带上颜色描边，左侧可以按颜色筛选。
何时用
用颜色标记进度，比如红色 = 待修、黄色 = 在做、绿色 = 已导出。
怎么调
设置 → 肉兔界面 →「影片库缩略图」（总开关）、「编辑时自动生成缩略图」、「影片库悬停预览」，默认都开。封面存在世界存档里（见附录 B），每部影片约 0.2 MB。

2.3影片体检

找出影片里缺的东西

一次检查这个世界的所有影片：打不开的文件、缺的模型 / 粒子 / 纹理 / 音频、没装插件的形态和关键帧，还会检查 BBS 自动备份是否完好。只读，不改任何东西。

入口
影片库右上角「列表 / 网格」右边的感叹号。
操作
点开后自动扫描，结果按问题类型列出，点影片名直接打开那部影片去修。
何时用
换电脑、整理或删除素材、导入别人发来的影片之后，以及正式导出前。
注意
联机时只有房主（或单人世界）能体检，因为影片存在房主电脑上。

2.4打开影片的窗口

全新影片库界面

影片编辑器里打开 / 管理影片的窗口，换成左边文件夹树、上面搜索框、可排序的布局。

操作
左边点「全部影片」或某个文件夹；搜索时显示完整路径，Esc 清空搜索；右键文件夹可「设为默认打开」。
怎么调
设置 → 肉兔界面 →「全新影片库界面」。
03

伪装界面

选形态的窗口换成：左边可折叠的目录树，中间所有分类连成的长列表，右边可收起的详情面板。目录可以自己整理、上色，只改显示，不动硬盘上的文件。

  1. 1搜索：左边每项显示命中数，回车选第一个结果，Esc 清空。
  2. 2顶栏按钮：切换搜索范围（全部 / 仅当前分类）、切换目录 / 专注模式、详情面板等。
  3. 3目录树：收藏、最近使用、我的分类、粒子和模型（按文件夹）、生物、杂项、其他插件的分类。点名字是跳转，点箭头才展开。
  4. 4上色：右键 →「设置颜色...」，颜色会带到下级和中间列表对应的区域。
  5. 5分类标题：中间长列表按左边目录的顺序排，滚动时左边跟着高亮。
  6. 6形态格子：粒子悬停时实时播放；没起名的粒子显示文件名。

3.1选形态

两种模式、收藏、详情

入口
回放编辑器 / 形态属性里点「选择」，或任何要选形态的地方。
操作
  • 两种模式：目录模式显示全部，点左边只是滚到那里；专注模式只显示选中的那一枝。
  • 收藏：右键形态或按 F；多选后右键「收藏所选」。拖到「收藏」或「我的分类」里是复制。
  • 详情面板：3D 预览、名字、ID、所在分类；编辑、收藏、复制形态、复制伪装命令、打开模型文件夹、在模型编辑器中打开。
  • 打开所在文件夹：粒子、图片、挤出图片、视频的格子右键都有（模型用 BBS 自带的「打开模型文件夹」）。
  • 记住位置：关掉再点「选择」，会回到上次看到的地方（本次游戏内）。右键分类「设为默认打开」则每次都先跳到这里。
何时用
给一排演员挨个换模型时，选完一个换下一个回放再点「选择」，还停在刚才那一屏。
怎么调
设置 → 肉兔界面 →「全新伪装界面布局」。窗口很窄时左边会缩成一列图标。

3.2整理目录

排序、虚拟文件夹、隐藏、上色、换图标

操作
  • 排序 / 挂到别处：按住左边的行上下拖；拖到另一项的中间就放进它下面。
  • 虚拟文件夹：右键「新建文件夹」，把分类或单个模型格子拖进去。右键模型「移回原位置」还原；「解散文件夹」把内容移回上一层。
  • 隐藏：右键「隐藏」；想找回来先右键「显示已隐藏项」，再「取消隐藏」。搜索时隐藏的也会出现。
  • 上色 / 图标：右键「设置颜色...」「更改图标...」。
  • 还原：右键「恢复默认排序」。
何时用
按项目整理：建一个「第三集」虚拟文件夹，把这一集要用的角色模型都拖进去；用不到的分类直接隐藏。
注意
这些都只改显示，模型和粒子在硬盘上的位置不变，贴图照常能找到。布局存在 morph_layout.json，换电脑时一起拷过去即可。

格子名字

操作
设置 → 肉兔界面 →「伪装格子名字」：模型、粒子、原版粒子、生物、方块、物品、图片、挤出图片、文字、结构、其他，各一个开关，默认全开。关掉后鼠标悬停仍会提示名字；没起名的原版粒子显示粒子类型（如 flame）。
何时用
方块、物品这类一眼能认出的可以关掉名字，画面更干净。
04

编辑器主页

模型编辑器、粒子编辑器、音频编辑器没打开文件时，显示资源工作台：文件夹树、收藏、搜索、最近打开、预览卡片。

  1. 1标题：资源总数和收藏数。
  2. 2搜索、按名称 / 最近排序、新建、打开文件夹、更多（数据管理、教程、Wiki 等）。
  3. 3左侧：收藏、全部、文件夹树（点箭头展开）。
  4. 4最近打开：最近编辑过的放在最前面。
  5. 5全部：带缩略图的卡片，下面一行灰字是所在文件夹。

资源工作台

入口
仪表盘 → 模型 / 粒子 / 音频编辑器，没打开文件的标签页。
操作
  • 双击打开编辑；卡片上的星标收藏。
  • 右键：打开、复制 ID、收藏、在数据管理中显示、打开所在文件夹；模型还有「用它伪装」（把你自己的玩家直接伪装成这个模型）。
  • Ctrl+滚轮调卡片大小。
何时用
素材多、记不住文件名时按缩略图找；试粒子时悬停就能看效果，不用一个个打开。
怎么调
设置 → 肉兔界面 →「资源面板主页（模型/粒子/音频）」，默认开。

粒子编辑器小改

操作
按 R 重启发射器（在文本框里打字时不会触发），调参数时随时重看一遍。顶栏的「重置布局」挪到了锁按钮的右键菜单里，不会再误点。
05

材质包预设

把一套材质包组合（启用哪些、什么顺序）存成预设，一键切换。

存预设、切预设

入口
选项 → 资源包。界面下方多了一行：最多 4 个预设的快捷按钮 + 「预设…」按钮。启动台左下角的「选项」也能进。
操作
  1. 先在原版界面把右栏的材质包排好。
  2. 点「预设…」→ 起个名字 →「保存当前组合」。
  3. 之后点快捷按钮（或预设界面里点名字）就换成这套并重新加载资源。
「覆盖」用当前右栏更新某个预设；「删除」要点两次确认。预设里有找不到的材质包会跳过并提示。
何时用
拍不同题材要换整套风格时（比如「写实」「原版」「卡通」），或者编辑时用低分辨率材质、导出前换高清材质。
怎么调
设置 → 肉兔界面 →「材质包预设」，关掉后资源包界面不显示这一行。

C

联机

封面怎么同步

  • 封面、预览帧、颜色标签保存在房主的世界里。房主装了肉兔界面（或 BBS++）时，所有装了的玩家看到同一份，有人改了其他人马上能看到。
  • 肉兔界面和 BBS++ 用的是同一套同步方式和同一个存放位置：朋友用 BBS++、你用肉兔界面，也能互相看到封面。
  • 房主没装时，封面只保存在你自己电脑上。
  • 没装的玩家照常玩，只是看不到这些界面，不会出错。

常见问题

启动台太大 / 太小？

设置 → 肉兔界面 →「启动台大小」。

只想要其中几块界面？

每块界面都是单独的开关，把不要的关掉就行，比如关掉「BBS-Rabbit 启动台」，其他照常。

影片库没有封面？

封面要在编辑器里用影片相机看过这部影片才会自动截（打开影片 1.5 秒后开始）。也可以右键录制按钮手动设。检查一下「影片库缩略图」和「编辑时自动生成缩略图」是不是开着。

伪装目录整理乱了？

右键「恢复默认排序」；或者关掉游戏删掉 morph_layout.json，全部回到默认。

和其他插件冲突？

本插件只依赖 BBS FS 2.7，可以和 BBS++ 一起装（注意上面安装里的提醒）。遇到问题请附上 logs/latest.log。

许可：LGPL-3.0-or-later，源码随发布一起提供（bbs-ui-rabbit-1.0.1-源码.zip）。
