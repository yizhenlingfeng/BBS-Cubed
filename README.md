### AAA 粒子

> 前置依赖：需安装 `aaa_particles-2.2.0` + `architectury`，未安装则自动禁用该功能。

- 新增 AAA 粒子伪装，粒子文件需存放至 `assets/effeks/` 目录
- 新增指令：`/bbsplusplus aaa_particle trigger <x> <y> <z> <触发器ID>`
  - 示例：`/bbsplusplus aaa_particle trigger 100 64 200 0`（触发指定坐标模型方块粒子的"触发器 0"）
- 已知限制：
  - 功能已通过基础稳定性测试（无崩溃），非崩溃级问题不再维护
  - 若加载粒子后游戏崩溃，请尝试使用新版 Effekseer 重新导出粒子文件

### Pose 帧增强

- 支持 pose 帧多选粘贴
- 骨骼参数刷：将骨骼参数复制到另一骨骼
- 改动骨骼标识：有改动的骨骼以橙色菱形标识提示
- 跳过当前帧骨骼关键值：将鼠标移到骨骼名称右侧边缘出现菱形，点击切换。跳过后仍保留该骨骼在当前帧的参数，但动画计算忽略此关键值，直接在前后有效 Pose 帧之间插值；灰色斜线菱形表示已跳过
- 移植自 FS 2.5 的树形骨骼功能并优化显示，默认关闭

### 附魔光效

- 姿势编辑页新增"附魔光效"开关，可为选中骨骼添加原版风格的附魔流光，无限循环无接缝
- 开关下方提供"光效颜色"取色器，可自定义流光颜色；默认白色为原版观感，透明度可同时调淡光效
- 右键开关或取色器可选择"应用到子骨骼"，将状态扩散到该骨骼的全部子骨骼（含未编辑过的子骨骼）
- 已知限制：Iris 光影包启用时流光暂不显示（关闭光影或仅在编辑器预览时正常）。原因是 Iris 对模组自定义核心 shader 存在原理性兼容限制，详见 Iris 文档 `docs/development/compatibility/core-shaders.md`

### 视频伪装

> 前置依赖：需安装 `MediaPlayer-BBS`，未安装则自动禁用该功能，仅支持 Windows x64 平台。

- 视频文件需放入 `<游戏目录>/config/bbs/assets/video/`（支持 .mp4 / .mov / .mkv / .webm / .avi / .m4v），可通过伪装编辑器中的"选择视频"面板打开该文件夹
- 兼容说明：`MediaPlayer-BBS 1.0.1` 的 native 时间轴寻帧接口存在崩溃缺陷，BBS Cubed 会自动禁用时间轴寻帧并退回连续解码路径；`MediaPlayer-BBS 1.0.2+`（修复构建）自动启用时间轴寻帧，支持拖动播放头逐帧精确定位。修复构建发布时请将版本号升至 1.0.2 以上

### 纹理补间

<div>
  <img src="docs/img_1.png" width="1000">
</div>

- 在纹理关键帧之间平滑过渡，支持三种补间模式：
  - **颜色**：在两张贴图之间按进度平滑插值颜色
  - **像素溶解**：像素按块随机溶解，过渡到下一张贴图
  - **消散**：从扩散起点向外逐块消散
- 消散模式支持搭配"消散倒退"（从透明逐步恢复）与"消散闪白"（变透明前显示闪光颜色，支持自定义颜色与 LabPBR 发光）
- 可调节像素块大小、扩散强度、闪光颜色、PBR 发光亮度等参数
- 内置 3D 扩散起点拾取器：在模型表面右键直接拾取消散起点，左键旋转、中键平移、Ctrl+滚轮缩放，X/Y/Z 支持数值微调
- 兼容旧版 BBSPPP 纹理补间关键帧数据，自动迁移

### CML 功能（合并自 bbs_snow）

> 原 bbs_snow 插件全部功能已合并进 BBS Cubed，模组 ID 统一为 `bbsplusplus`，资源命名空间 `bbspp`。安装本模组后无需再单独安装 bbs_snow。

- **流体模拟**：新增流体伪装，支持流体物理模拟渲染
- **粒子 Plus**：增强粒子系统——粒子变形（Morph）、碰撞外观与染色、收藏夹浏览器、附加渲染纹理、Additive 材质
- **PBR 纹理分级**：逐骨骼/逐组 PBR 参数覆盖（光滑度、金属度、孔隙率、自发光、法线强度）
- **骨骼纹理**：逐骨骼分配独立纹理
- **Premiere 导出**：将影片导出为 Premiere Pro XML 工程文件，同时生成 SRT 字幕文件
- **三种剪辑类型**：快捷栏剪辑、电影剪辑、重播剪辑
- **动作叠加**：每个模型表单可配置动作叠加层（actions_overlay），播放时与基础动作混合
- **Additive 动画**：叠加动画支持，多动作层混合计算
- **Molang 变量共享**：variable 动作模型互通开关，开启后不同动作间共享 Molang 变量
- **动画态编辑器**：动画状态编辑与布局增强，支持姿势插入
- **迷你窗口**：可停靠迷你窗口系统（影片面板、仪表盘等），支持拖拽与布局记忆
- **回放时间控制**：重播剪辑支持速度调节、反向播放、传播范围设置
- **剪辑可见性**：可临时隐藏指定剪辑
- **关键帧编辑器增强**：分割视图、嵌入检查器、动作时间线评估、PBR 关键帧工厂
- **CML 设置面板**：独立设置模块，包含通用、外观、编辑器、显示、流体模拟、模型方块、姿势轨道选择、重播编辑器等分类

### MOD 更新日志

#### 3.5.6（修复退出世界崩溃）：
* **修复退出/切换世界时 JVM 崩溃**：退出世界时 BBS 会在 Netty 客户端 IO 线程上直接调用 `glDeleteTextures` 等 OpenGL 函数释放视频纹理，而该线程没有当前 GL 上下文，导致 LWJGL 抛出 "No context is current" 并直接终止 JVM。现已将视频资源删除、影片控制器关闭、相机重置等 GL 清理操作统一调度回渲染线程执行，退出世界不再崩溃
* **修复 Bedrock 单数字缩放动画无效**：修复 `"scale": 2` 这类 Bedrock 简写在 BBS 中被忽略、骨骼缩放没反应的问题；现在单值会自动按三轴同值处理，`"position": 0.5`、`"rotation": 90` 等同理支持

#### 3.5.5（IK 目标可选 + BBS 2.7 伪装注册修复）：
* **新增 IK 目标约束开关**：BBS 增强中新增"IK 目标约束"选项（默认开启）。开启时保持原版行为，IK 目标不能选择本 IK 链自身骨骼以避免循环；关闭后允许选择链上骨骼作为 IK 目标，可用于连锁或循环约束
* **修复 snow_actions 伪装飞行动作鬼畜**：恢复动作时间线帧传播，并移植防抖修复线，飞行、飞行待机、游泳、骑乘等状态动作连续播放，非循环动作不再出现 fadeOut 弹跳
* **修复 BBS 2.7 下 AAA 粒子与物品喷射伪装从伪装页消失**：BBS 2.7 调整资源重载时序后，启动期反射注入到额外分类的伪装表单会被重建冲掉；改为在每次分类重建时统一挂载 FluidForm、AAAParticleForm、ItemSprayForm
* **修复自动保存预设按钮视觉状态不同步**：右键菜单中"自动保存"按钮的图标颜色随开关状态同步（关 = 灰、开 = 白）；未选中预设时自动回退到当前参数匹配的预设或第一个预设

#### 3.5.4（物理化修复 + Lezy 相机效果汉化）：
* 修复物理化肢体不跟随线框移动的问题
* 修复 snow_actions 飞行动画抽搐问题
* snow_actions 默认关闭，需在设置中手动开启
* 补全 Lezy 相机效果片段（调色、电影感、黑边、暗角）关键帧轨道名汉化
* 支持双击 BBS 内置剪辑及第三方 addon（如 Lezy）提供的剪辑进入关键帧编辑

#### 3.5.3（撤销重做 + Premiere 导出修复）：
* 模型方块预览主页新增撤销/重做支持（Ctrl+Z / Ctrl+Y），连续快速修改自动合并为一步
