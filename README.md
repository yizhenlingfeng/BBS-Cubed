### 全新影片库

开启「全新影片库界面」后，影片面板的主页会替换为影片库工作区：

- **快捷栏**：最左侧固定常用文件夹。右键文件夹选择「固定到快捷栏」，点击快捷项即可定位
- **根目录列**：快捷栏右侧始终是根目录列，根目录下可以直接新建影片
- **向右展开**：点击文件夹会在右侧新增子列，可不断向右展开；列超出可用宽度时所有列自动等比收窄，收窄到最小宽度后才横向滚动
- **每列内容**：子文件夹在上、直属影片在下，底部提供「＋ 创建影片」；拖动影片到任意文件夹行或列即可移动
- **交互**：单击选中、双击打开；右键菜单支持新建、重命名、删除、固定快捷栏；顶部保留搜索与名称排序
- 关闭开关后恢复 BBS 原版影片选择界面

### 影片编辑器时间轴锁定

- **右键锁定**：右键点击顶部切换编辑器的图标，可在菜单中「锁定时间轴 / 解锁时间轴」；锁定后工具栏图标变暗
- **只限制快捷键**：锁定不会禁用编辑器，仍可点击图标进入锁定模式；按 `·` 切换编辑器时只会经过未锁定的模式
- **按影片保存**：锁定状态随影片数据保存，不写入全局配置；切换影片或重启游戏后仍会恢复，且至少保留一个未锁定模式
- **POV 支持**：安装 BBS-POV 时，POV 编辑器同样参与锁定，并支持与摄像机/回放一致的右键「转为小窗 / 还原」

### AAA 粒子

> 前置依赖：需安装 `aaa_particles-2.2.0 ~ 2.3.4` + `architectury`，未安装则自动禁用该功能。

- 新增 AAA 粒子伪装，粒子文件需存放至 `assets/effeks/` 目录
- 触发器：可在表单关键帧中驱动 `trigger0-3`；`/bbsplusplus aaa_particle trigger <x> <y> <z> <0-3>` 在单人/集成服务器中通过本地客户端触发（远程服务器不加载本模组，指令不可用）
- 已知限制：
  - 功能已通过基础稳定性测试（无崩溃），非崩溃级问题不再维护
  - 若加载粒子后游戏崩溃，请尝试使用新版 Effekseer 重新导出粒子文件

### Pose 帧增强

- 支持 pose 帧多选粘贴
- 骨骼参数刷：将骨骼参数复制到另一骨骼
- 改动骨骼标识：有改动的骨骼以橙色菱形标识提示
- 跳过当前帧骨骼关键值：将鼠标移到骨骼名称右侧边缘出现菱形，点击切换。跳过后仍保留该骨骼在当前帧的参数，但动画计算忽略此关键值，直接在前后有效 Pose 帧之间插值；灰色斜线菱形表示已跳过
- 移植自 FS 2.5 的树形骨骼功能并优化显示，默认关闭

### 附魔光效

- 姿势编辑页提供「附魔光效」栏，可为选中骨骼启用原版风格的循环流光；该栏始终显示，不再由模组设置开关控制。
- 影片编辑器中，肢体轨道关键帧的属性面板同样提供「附魔光效」栏，可直接在影片时间线上按骨骼调整；姿势轨道关键帧面板中的该栏作用于当前选中的骨骼。
- 支持自定义颜色与透明度，并可调整流动速度（0–4 倍）与亮度（0–4 倍）；右键可将当前设置应用到子骨骼。
- 未启用光影时使用模组内置 shader；启用 Iris 光影后，光效改由光影包的 glint 程序绘制。两条路径共用同一相位，开关光影不会改变流速。
- 若光影包未提供 `gbuffers_armor_glint`，Iris 会回退到 `gbuffers_textured`，最终观感取决于光影包。
- 兼容说明：若已安装注册 `bbs:cinematic` 的第三方模组（如 BBS Lezy / Better Camera Perspective），本模组不覆盖该剪辑，电影效果由对方提供。

### 结构与破坏魔杖增强

> 光影曲线等能力合并自"卫巾纸薄"的 tools 插件；结构伪装本体由 BBS 2.7 内置。

- BBS 2.7 已内置结构棒与结构伪装
- 本模组补充 VFX / Xavin 破坏魔杖的选区交互、操作提示与音效（需安装对应插件）

### 视频伪装

> 前置依赖：需安装 `MediaPlayer-BBS`，未安装则自动禁用该功能，仅支持 Windows x64 平台。

- 视频文件需放入 `<游戏目录>/config/bbs/assets/video/`（支持 .mp4 / .mov / .mkv / .webm / .avi / .m4v），可通过伪装编辑器中的"选择视频"面板打开该文件夹
- 兼容说明：`MediaPlayer-BBS 1.0.1` 的 native 时间轴寻帧接口存在崩溃缺陷，BBS Cubed 会自动禁用时间轴寻帧并退回连续解码路径；`MediaPlayer-BBS 1.0.2+`（修复构建）自动启用时间轴寻帧，支持拖动播放头逐帧精确定位。修复构建发布时请将版本号升至 1.0.2 以上

### 纹理补间

<div>
  <img src="docs/img_1.png" width="1000">
</div>

- 在纹理关键帧之间平滑过渡，支持三种补间模式：
  - **颜色**：在两张贴图之间按进度平滑插值颜色
  - **像素溶解**：像素按块随机溶解，过渡到下一张贴图
  - **消散**：从扩散起点向外逐块消散
- 消散模式支持搭配"消散倒退"（从透明逐步恢复）与"消散闪白"（变透明前显示闪光颜色，支持自定义颜色与 LabPBR 发光）
- 可调节像素块大小、扩散强度、闪光颜色、PBR 发光亮度等参数
- 内置 3D 扩散起点拾取器：在模型表面右键直接拾取消散起点，左键旋转、中键平移、Ctrl+滚轮缩放，X/Y/Z 支持数值微调
- 兼容旧版 BBSPPP 纹理补间关键帧数据，自动迁移

### 模型描边

- 描边设置位于姿势编辑器「PBR」栏下方的可折叠「描边」栏中，按骨骼独立配置；展开后可为当前骨骼开启描边，并调整颜色、宽度、辉光与「不描边块尺寸」
- 影片编辑器中，肢体轨道关键帧的属性面板同样提供「描边」栏，可直接在影片时间线上按骨骼配置。
- 与 PBR、附魔光效一致，描边参数保存在骨骼的姿势数据中，可随关键帧插值，不再写入模型 `config.json`
- 开启后仅绘制骨骼轮廓外缘：透明贴图区域不产生描边；焊接面自动跳过；被更大方块完全包裹的小型装饰块可通过「不描边块尺寸」过滤
- 「不描边块尺寸」以模型像素为单位，`0` 表示关闭过滤；宽度以 1/4 模型像素为单位，`4` 约等于 1 个模型像素
- 右键描边开关、颜色或任一参数滑条，选择「应用到子骨骼」，可将设置扩散到该骨骼的全部子骨骼
- 辉光范围为 0–255，`0` 表示关闭；1.20.1 / 1.20.4 在安装 Iris 时使用 LabPBR 自发光绘制辉光，未安装 Iris 或纹理不可用时回退为纯色描边；1.21.11 目前支持纯色描边与深度补写，LabPBR 辉光仍在适配中
- 同一面板下方的「附魔光效」栏也已合并为可折叠栏，包含光效开关、颜色、流动速度与亮度，便于与描边参数一并管理
- 迁移说明：描边不再读取模型 `config.json` 中的旧描边键；已有工程需在姿势编辑器中按骨骼重新开启，可使用「应用到子骨骼」快速铺开

### 纹理变换

- 模型形态编辑页底部提供可折叠的「纹理变换」栏，可调整贴图的 UV 偏移与缩放。
- UV 是表单级属性，与单根骨骼及其关键帧无关；影片姿势 / 肢体轨道面板不提供该栏，避免与逐骨骼数据混淆。
- 1.20.1 / 1.20.4 下，纹理变换同时应用于模型渲染 shader 与内置附魔光效 shader，开启附魔光效后 UV 调整仍然生效。

### CML 功能（合并自 bbs_snow）

> 原 bbs_snow 插件全部功能已合并进 BBS Cubed，模组 ID 统一为 `bbsplusplus`，资源命名空间 `bbspp`。安装本模组后无需再单独安装 bbs_snow。

- **流体模拟**：新增流体伪装，支持流体物理模拟渲染
- **粒子 Plus**：增强粒子系统——粒子变形（Morph）、碰撞外观与染色、收藏夹浏览器、附加渲染纹理、Additive 材质
- **PBR 纹理分级**：逐骨骼/逐组 PBR 参数覆盖（光滑度、金属度、孔隙率、自发光、法线强度）
- **骨骼纹理**：逐骨骼分配独立纹理
- **Premiere 导出**：将影片导出为 Premiere Pro XML 工程文件，同时生成 SRT 字幕文件
- **三种剪辑类型**：快捷栏剪辑、电影剪辑、重播剪辑
- **动作叠加**：每个模型表单可配置动作叠加层（actions_overlay），播放时与基础动作混合
- **动作时间线端点**：在动作轨道选中动作、选定动画后，自动在动画结束处插入成对的端点关键帧，形成可裁剪、可循环、可叠加的动作片段；由设置「动画轨道创建起始帧」控制
- **Additive 动画**：叠加动画支持，多动作层混合计算
- **Molang 变量共享**：variable 动作模型互通开关，开启后不同动作间共享 Molang 变量
- **动画态编辑器**：动画状态编辑与布局增强，支持姿势插入
- **迷你窗口**：可停靠迷你窗口系统（影片面板、仪表盘等），支持拖拽与布局记忆
- **回放时间控制**：重播剪辑支持速度调节、反向播放、传播范围设置
- **剪辑可见性**：可临时隐藏指定剪辑
- **关键帧编辑器增强**：分割视图、嵌入检查器、动作时间线评估、PBR 关键帧工厂
- **CML 设置面板**：独立设置模块，包含通用、外观、编辑器、显示、流体模拟、模型方块、姿势轨道选择、重播编辑器等分类

### MOD 更新日志

#### 3.6.6（Bedrock 步阶帧与插值读取修正）：
* **步阶帧判定**：此前只要关键帧带 `pre` 即判定为步阶帧，而 Blockbench 对含前值的关键帧一律写入 `pre` 与 `post`（平滑关键帧两者相同），导致平滑动画被当作步阶播放。现按动画文件中的插值声明判定：本帧 `pre` 与 `post` 不同，或上一帧声明 `easing` 为 `step`，才视为步阶帧
* **步阶帧插值**：步阶帧使用 BBS 内置的步阶插值（`CONST`），方块模型动画按段内后一帧取插值时即可正确保持前值并在该帧瞬跳
* **步阶帧之后的动画段**：动画转姿势关键帧时，步阶帧的插值曾被一并写入姿势关键帧，使离开该帧的一段同样被保持。现改为沿用下一帧的插值，离开步阶帧的段落恢复平滑
* **姿态烘焙**：同样保留步阶帧，且不会多保持一段
* 以上修正仅影响含步阶帧的动画，纯 catmullrom 与线性动画的播放不受影响

#### 3.6.2（穿透粒子导致编辑器预览黑屏修复）：
* **问题现象**：场景中存在开启了「穿透渲染」（忽略深度，X-Ray）的 AAA 粒子时，打开模型方块页、影片页等编辑器预览界面，3D 视口会整片纯黑（只显示侧栏 UI 与 gizmo），或反过来被整张方块图集铺满，且日志中没有任何报错
* **根本原因**：穿透渲染需要在主渲染流程之外额外再绘制一遍粒子。Effekseer 的 C++ 底层会绕过 Minecraft 的 `RenderSystem` 直接调用 `glActiveTexture` / `glBindTexture` 改写真实纹理绑定，`RenderSystem` 的贴图缓存因此与 GL 实际状态脱节；后续绘制认为贴图已绑定而跳过重绑，采样到空贴图或方块图集，整片视口随之变黑或铺满图集
* **状态还原**：穿透渲染段改为 `try/finally` 结构，深度范围、深度函数、深度写入、深度测试、帧缓冲绑定与视口在退出时按进入前的原值无条件还原，不再受绘制中途异常影响
* **纹理缓存校正**：退出时把 0~7 号纹理单元按 GL 的真实绑定重新经 `RenderSystem` 绑定一次（绑定值不变，仅校正缓存），既清掉 Effekseer 留下的状态，也不再出现"清空绑定导致全黑、回滚绑定导致图集铺屏"的问题
* **兼容性**：修复位于穿透渲染的独立绘制段，不影响 AAA 粒子本身的显示、穿透效果与透明排序

* **新增 G/S/R 保持原版切换**：开启后第 2 次按 G/S/R 不恢复上一模式，保持原版 BBS 的直接切换行为

* **修复装有 IRLite 1.0 时客户端启动崩溃**：IRLite 1.1.x 给 `renderGuide` 追加了 `boolean guideVisible` 参数，3.5.1 起本模组的注入回调跟着改成三参，只按方法名匹配时 Mixin 仍会先找到旧版两参方法再做描述符校验，直接抛 `InvalidInjectionException` 让整个客户端在初始化阶段崩掉（`require = 0` 拦不住）。现在按版本拆成两个注入器并各自写完整描述符，IRLite 1.0 与 1.1.x 都能正常启动，导引线/模具手柄的隐藏行为保持不变

#### 3.5.6（动画悬停预览 + 退出世界崩溃修复 + 快捷键冲突提示）：
* **新增动作编辑器动画悬停预览**：模型编辑器"动作"页动画列表中，鼠标停在动画条目上时从该条目下方弹出正方形预览栏，循环播放对应动画；预览栏按模型包围盒自动缩放填满，仅作预览不影响编辑
* **修复退出/切换世界时 JVM 崩溃**：退出世界时 BBS 会在 Netty 客户端 IO 线程上直接调用 `glDeleteTextures` 等 OpenGL 函数释放视频纹理，而该线程没有当前 GL 上下文，导致 LWJGL 抛出 "No context is current" 并直接终止 JVM。现已将视频资源删除、影片控制器关闭、相机重置等 GL 清理操作统一调度回渲染线程执行，退出世界不再崩溃
* **修复 Bedrock 单数字缩放动画无效**：修复 `"scale": 2` 这类 Bedrock 简写在 BBS 中被忽略、骨骼缩放没反应的问题；现在单值会自动按三轴同值处理，`"position": 0.5`、`"rotation": 90` 等同理支持
* **新增快捷键冲突提示开关**：BBS 增强中新增"快捷键冲突提示"（默认关闭）。开启后，按键绑定设置页中完全重复的按键会以黄色字体显示，按键框左侧出现黄色叹号；悬停叹号列出所有共用此按键的功能，点击叹号自动跳转到冲突所在行（同分类滚动定位，跨分类自动切换分类并滚动到位）；左右 Shift/Ctrl/Alt 视为等效
* **调整"与上一个镜头模式循环"默认键位为 Q**：从原 R 改为 Q，避免与原版 R 键冲突；已有自定义键位的存档不受影响
