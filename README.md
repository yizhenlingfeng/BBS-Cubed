### 全新影片库

开启「影片库工作区」后，影片面板的主页会替换为影片库工作区：

- **快捷栏**：最左侧固定常用文件夹。右键文件夹选择「固定到快捷栏」，点击快捷项即可定位
- **根目录列**：快捷栏右侧始终是根目录列，根目录下可以直接新建影片
- **向右展开**：点击文件夹会在右侧新增子列，可不断向右展开；列超出可用宽度时所有列自动等比收窄，收窄到最小宽度后才横向滚动
- **每列内容**：子文件夹在上、直属影片在下，底部提供「＋ 创建影片」；拖动影片到任意文件夹行或列即可移动
- **交互**：单击选中、双击打开；右键菜单支持新建、重命名、删除、固定快捷栏；顶部保留搜索与名称排序
- 关闭开关后恢复 BBS 原版影片选择界面

### 影片编辑器时间轴锁定

- **右键锁定**：右键点击顶部切换编辑器的图标，可在菜单中「锁定时间轴 / 解锁时间轴」；锁定后工具栏图标变暗
- **只限制快捷键**：锁定不会禁用编辑器，仍可点击图标进入锁定模式；按 `·` 切换编辑器时只会经过未锁定的模式
- **按影片保存**：锁定状态随影片数据保存，不写入全局配置；切换影片或重启游戏后仍会恢复，且至少保留一个未锁定模式
- **POV 支持**：安装 BBS-POV 时，POV 编辑器同样参与锁定，并支持与摄像机/回放一致的右键「转为小窗 / 还原」

### AAA 粒子

> 前置依赖：需安装 `aaa_particles-2.2.0 ~ 2.3.4` + `architectury`，未安装则自动禁用该功能。

- 新增 AAA 粒子伪装，粒子文件需存放至 `assets/effeks/` 目录
- 触发器：可在表单关键帧中驱动 `trigger0-3`；`/bbsplusplus aaa_particle trigger <x> <y> <z> <0-3>` 在单人/集成服务器中通过本地客户端触发（远程服务器不加载本模组，指令不可用）
- 已知限制：
  - 功能已通过基础稳定性测试（无崩溃），非崩溃级问题不再维护
  - 若加载粒子后游戏崩溃，请尝试使用新版 Effekseer 重新导出粒子文件

### 粒子 Plus

- **粒子变形（Morph）**：为粒子指定一份表单，用它替换原版的贴图公告板并逐粒子绘制；可勾选静态空间，并按旋转 / 朝向等面向模式让截面始终对准镜头，同时沿用粒子自身的纹理缩放与表单缩放
- **碰撞外观与碰撞染色**：粒子撞到方块或实体后切换为指定外观，或按碰撞结果着色
- **Additive 材质**：粒子材质下拉新增「Additive」，以叠加方式混合；1.21.11 上为此自建专用渲染管线，创建失败时自动回落到普通粒子层，仅表现为叠加失效
- **另存为**：粒子编辑器可把当前方案复制为一份新文件，并直接在副本上继续编辑
- **撤销**：1.20.1 由模组提供快照式撤销，连续改动按 300 毫秒防抖合并为一条记录，支持 `Ctrl+Z` / `Ctrl+Y` 与历史面板；1.21.11 改用面板自带的撤销，两者不会叠加

### Pose 帧增强

- 支持 pose 帧多选粘贴
- 骨骼参数刷：将骨骼参数复制到另一骨骼
- 改动骨骼标识：有改动的骨骼以橙色菱形标识提示
- 跳过当前帧骨骼关键值：将鼠标移到骨骼名称右侧边缘出现菱形，点击切换。跳过后仍保留该骨骼在当前帧的参数，但动画计算忽略此关键值，直接在前后有效 Pose 帧之间插值；灰色斜线菱形表示已跳过
- 移植自 FS 2.5 的树形骨骼功能并优化显示，默认关闭

### 附魔光效

- 姿势编辑页提供「附魔光效」栏，可为选中骨骼启用原版风格的循环流光；该栏始终显示，不再由模组设置开关控制。
- 影片编辑器中，肢体轨道关键帧的属性面板同样提供「附魔光效」栏，可直接在影片时间线上按骨骼调整；姿势轨道关键帧面板中的该栏作用于当前选中的骨骼。
- 支持自定义颜色与透明度，并可调整流动速度（0–4 倍）与亮度（0–4 倍）；右键可将当前设置应用到子骨骼。
- 未启用光影时使用模组内置 shader；启用 Iris 光影后，光效改由光影包的 glint 程序绘制。两条路径共用同一相位，开关光影不会改变流速。
- 若光影包未提供 `gbuffers_armor_glint`，Iris 会回退到 `gbuffers_textured`，最终观感取决于光影包。
- 兼容说明：若已安装注册 `bbs:cinematic` 的第三方模组（如 BBS Lezy / Better Camera Perspective），本模组不覆盖该剪辑，电影效果由对方提供。

### 视频伪装

> 前置依赖：需安装 `MediaPlayer-BBS`，未安装则自动禁用该功能，仅支持 Windows x64 平台。

- 视频文件需放入 `<游戏目录>/config/bbs/assets/video/`（支持 .mp4 / .mov / .mkv / .webm / .avi / .m4v），可通过伪装编辑器中的"选择视频"面板打开该文件夹
- 兼容说明：`MediaPlayer-BBS 1.0.1` 的 native 时间轴寻帧接口存在崩溃缺陷，BBS Cubed 会自动禁用时间轴寻帧并退回连续解码路径；`MediaPlayer-BBS 1.0.2+`（修复构建）自动启用时间轴寻帧，支持拖动播放头逐帧精确定位。修复构建发布时请将版本号升至 1.0.2 以上

### 纹理补间

- 在纹理关键帧之间平滑过渡，支持三种补间模式：
  - **颜色**：在两张贴图之间按进度平滑插值颜色

- 内置 3D 扩散起点拾取器：在模型表面右键直接拾取消散起点，左键旋转、中键平移、Ctrl+滚轮缩放，X/Y/Z 支持数值微调
- 兼容旧版 BBSPPP 纹理补间关键帧数据，自动迁移

### 模型描边

- 描边设置位于姿势编辑器「PBR」栏下方的可折叠「描边」栏中，按骨骼独立配置；展开后可为当前骨骼开启描边，并调整颜色、宽度、发光、面剔除与「不描边块尺寸」
- 影片编辑器中，肢体轨道关键帧的属性面板同样提供「描边」栏，可直接在影片时间线上按骨骼配置。
- 与 PBR、附魔光效一致，描边参数保存在骨骼的姿势数据中，可随关键帧插值，不再写入模型 `config.json`
- 开启后仅绘制骨骼轮廓外缘：透明贴图区域不产生描边；焊接面自动跳过；被更大方块完全包裹的小型装饰块可通过「不描边块尺寸」过滤
- 「不描边块尺寸」以模型像素为单位，`0` 表示关闭过滤；宽度以 1/4 模型像素为单位，`4` 约等于 1 个模型像素
- 右键描边开关、颜色、面剔除或任一参数滑条，选择「应用到子骨骼」，可将设置扩散到该骨骼的全部子骨骼
- 「启用描边」上方新增整行「全部应用到子集」按钮：一次把两层描边的全部参数（颜色、渐变、宽度、发光、面剔除、逐面颜色与渐变）复制给该骨骼的所有子骨骼，不必再逐项右键
- 「发光」写入 LabPBR 自发光通道：`0` 为不发光，`1`–`254` 沿该通道线性增强。它需要安装 Iris，且所用光影包声明了 `normals` / `specular` 采样器才会显现；不满足时描边仍是纯色外壳，只是没有自发光
- 「面剔除」默认开启。关闭后描边壳两侧都绘制，薄片与贴片类方块在任何角度都能看见描边，代价是顶点数翻倍
- 各层互不影响：纯色外壳始终包含全部描边骨骼，发光只在它之上叠加亮度，不会改变描边轮廓或基础颜色
- 「叠加描边」开关位于描边栏最后一行。开启后该骨骼在当前描边之外再套一层描边，并在下方展开一个与之完全对等的「描边叠加」栏：两层各有独立的颜色、宽度、发光、面剔除与逐面颜色，互不覆盖；第二层的宽度表示在里层外面再向外扩出多少，默认 `4`（1 个模型像素），两层的宽度按降序绘制，里层始终压在宽的那层之上形成双环
- 每栏底部有可折叠的「高级选项」子栏，可为前 / 右 / 后 / 左 / 上 / 下六个面单独取色；未设置过的面跟随该层主色，「全部跟随主颜色」按钮可一次把六个面交还给主色。面颜色整块取色而不参与插值，避免关键帧之间插出中间色
- 颜色行右侧图标组里的模式图标用于在「纯色」与「渐变」之间切换。纯色模式下行内只排两枚图标（模式、色块），切到渐变时才在最左侧补出「应用到子骨骼」，原色块的位置变为方向按钮并贴在色块左缘，三枚图标因此相邻；颜色行下方同时展开渐变编辑条，与左侧的色标色块之间留出间距
- 渐变编辑条左侧的色块修改当前选中色标的颜色；拖动色标调整位置，右键渐变条可新增或删除色标（至少保留一个）。色标位置与颜色随骨骼姿势保存，并写入关键帧
- 主色渐变按屏幕方向投影：上下方向沿屏幕竖直轴、左右方向沿屏幕水平轴，投影范围取模型包围盒在这两个方向上的跨度，所以无论从哪个角度看，描边都保持一整条渐变，不会在正对某个模型轴时塌成一圈纯色；相机转动时外壳会按新方向重新烘焙。逐面渐变仍按每个面的水平 / 垂直双轴投影：前、后、左、右四个面为 X / Y，上、下两个面为 X / Z，因此模型旋转后仍按该面自身的方向渐变
- 优先级为「面渐变 > 面纯色 > 主渐变 > 主纯色」：某个面单独设置了渐变或颜色时，该面不再使用主色渐变；未单独设置的面继续跟随主层
- 渐变模式下颜色行左侧的「应用到子骨骼」图标把当前渐变复制给全部子骨骼；纯色模式该图标隐藏（同一操作改用右键色块），复制时也会清除子骨骼上残留的渐变，避免子骨骼继续显示旧渐变
- 「全部跟随主颜色」在渐变模式下会同时清除六个面的渐变
- 逐面颜色同时作用于描边本体与发光层：LabPBR 自发光按面颜色分批绘制，开启光影时也不会把六个面重新刷回该层主色
- 高级选项里的每个面颜色色块都支持右键「应用到子骨骼」；「全部跟随主颜色」按钮的右键只保留「应用到子骨骼」一项（把六个面一起交还主色）
- 1.21.11 目前支持纯色与渐变描边与深度补写，LabPBR 自发光仍在适配中
- 同一面板下方的「附魔光效」栏也已合并为可折叠栏，包含光效开关、颜色、流动速度与亮度，便于与描边参数一并管理
- 迁移说明：描边不再读取模型 `config.json` 中的旧描边键；已有工程需在姿势编辑器中按骨骼重新开启，可使用「应用到子骨骼」快速铺开

### 纹理变换

- 模型形态编辑页底部提供可折叠的「纹理变换」栏，可调整贴图的 UV 偏移与缩放。
- UV 是表单级属性，与单根骨骼及其关键帧无关；影片姿势 / 肢体轨道面板不提供该栏，避免与逐骨骼数据混淆。
- 1.20.1 / 1.20.4 下，纹理变换同时应用于模型渲染 shader 与内置附魔光效 shader，开启附魔光效后 UV 调整仍然生效。

### 肢体选择

- 在伪装编辑器的模型预览中，用普通左键点击可见肢体即可选中对应骨骼。1.21.11 开启 Iris 光影或模型描边时也支持此操作。
- 按住 `E`（可在按键绑定「变换」分类改绑）进入肢体选择模式，松开立即恢复；仅在 BBS 界面内生效，文本框聚焦时自动让路。
- **左键 / 右键**：左键选中点击到的实际肢体（忽略骨骼选取覆盖），右键按骨骼选取覆盖选中。骨骼覆盖的映射放在读取拾取结果的那一刻完成，模板缓冲区停留在上一帧也不会选错骨骼。
- **新建关键帧**：动画态编辑器或影片回放面板打开时，按住期间左右键都会直接为目标骨骼新建关键帧——左键给实际肢体，右键给覆盖指向的骨骼。
- **专注显示**：按住期间隐藏操控器、坐标轴、摄像机参考线与 IK 调试层，命中框也不再绘制；模型改用原版实体着色器，并把当前选中的演员压在其他模型之前。预览地面网格与 UI 面板保持原样。
- **性能与提示**：切换着色器保留 GPU 的 VAO 渲染路径，场景里演员较多也不会掉帧；按键绑定页悬停「肢体选择」可查看分步用法。

## 代码组织

本项目的增强通过 Mixin 访问上游私有成员，为便于维护与排查，同类访问只保留一处定义：

- **单一 Accessor 定义**：`gbeic.bbsplusplus.mixin.client.accessor` 下的接口是唯一实现，并在 mixin 配置中注册；`gbeic.bbsplusplus.api` 不再保留功能重复的第二份声明，调用方统一引用 mixin 侧接口
- **同类注入合并**：目标方法与注入点完全一致的多个 Mixin 合并为一个多目标 `@Mixin`，例如模型根变换、肢体、锚点三类轨道共用的「重置变换」；不再按轨道复制实现
- **版本适配器**：两侧差异只是少量 API 改名或包路径移动时，共享源码调用版本侧的小适配器（如相机矩阵、渲染事件注册、图标矩阵、GameMode 读写），而不是在共享层写版本判断
- **构建目标分离**：`src/main/java` 为共享源码，`src/main/java-1.20.x` 与 `src/main/java-1.21.11` 存放版本专属实现，构建时按目标版本选择其一，因此同一版本目录内不应出现需要按条件排除的同名文件
- **兼容性校验**：`scripts/check-class-diff.ps1` 对比 1.20.1 与 1.21.11 两个产物，以白名单逐条登记「仅存在于某一版本」的类，只有出现未登记的缺失类才判定为回归

#### 3.6.9（修复与 BBS-POV 的注入冲突 + 可配置变换步长 + 动画烘焙性能）：
* **重采样动作守卫恢复生效**：BBS-POV 1.0.1 在 `Replay#applyClientActions` 中对 `ActionClip.applyClient` 挂了 `@Redirect`，而同一调用点只允许一个，本模组先前挂在该处的同点注入被静默跳过，时间重采样时的不可逆动作拦截随之失效（不报错、不崩溃）。现改为注入 `ActionClip#applyClient` 方法头，两个模组可同时生效；`require` 由 `0` 升为 `1`，签名一旦变动会在启动阶段直接报错
* **变换步长可配置**：设置面板「姿势与动画」新增位移、缩放、欧拉旋转、锚点四个步长项，默认 0.062 / 0.25 / 15 / 0.062，与原版单次点按箭头或 Ctrl 拖动一致，调整后立即生效。只改步长，四元数旋转行与普通拖动的灵敏度保持原版
* **设置右键重置**：本模组设置页每一项都能右键「重置数值」，包括仍停在默认值、原版因此不显示该项的设置与自定义行，重置后立即刷新
* **动画烘焙改为按需后台执行**：仅在选中动画状态后，才使用独立的模型、动画和 Molang 快照在后台采样，避免预加载全部动画占用内存；状态列表实时显示进度，切换状态时取消其他未完成任务，完成后在渲染线程提交并合并为一条撤销记录。取消姿势关键帧数量上限，空动画自动忽略
* **修复空动作叠加层导致 YSM 动作抽搐**：开启 `snow_actions` 后，空叠加层会被 BBS 补成默认 `idle` 动作并与 YSM 当前动作重复叠加。现仅在实际配置了动作的叠加层上创建动画器，原生 YSM 播放不再受空叠加层干扰，已有时间轴和叠加配置保持有效
* **降低烘焙与预览开销**：姿势关键帧仅保留动画涉及的骨骼，避免保存整份模型数据；模型预览按渲染帧复用光效扫描结果，减少重复骨骼遍历和临时对象创建
* **粒子 Plus 移植到 1.21.11**：粒子变形、碰撞外观与碰撞染色、Additive 材质与编辑器界面均与 1.20.1 行为一致，1.21.11 专属注入自检由 18 条增至 21 条。Additive 改为自建渲染管线——上游只提供不透明与混合两条，1.21.11 也无法临时改混合状态——创建失败时回落普通粒子层；修复预览中铺满视口的纯红矩形（坐标轴把只含旋转的 `camera.view` 当作完整相机矩阵，缺了 `camera.position` 的平移）；`sun.misc.Unsafe` 不再静态引用（Java 21 下该包不可见），改为运行时反射；源码按版本分目录，文件操作控件在 1.21.11 只保留另存为，撤销交给上游面板
* **代码整理**：合并五组重复的 `@Accessor` 声明（影片控制器、剪辑、剪辑面板、面板停靠布局、影片面板布局），每个目标只保留 `mixin.client.accessor` 下的唯一接口并统一调用方，`api` 包中功能重复的第二份声明已移除；注入方法名保持不变，对已有行为与存档无影响。模型根变换、肢体、锚点三类轨道的「重置变换」合并为一个多目标 Mixin，同时修复多选关键帧时只有主关键帧真正归零的问题。`/bbsplusplus debug` 的两个同义格式化方法合并为一个，输出文本不变。空覆盖方法与私有成员经逐条审核均有正当用途（接口抽象方法、`@Shadow` 声明、刻意留空以屏蔽原版行为、Mixin 注入处理器），未作删除；本阶段触碰的文件另外清理了内联全限定名与过时注释。`scripts/check-class-diff.ps1` 由「缺失类数量不超过基线」改为白名单精确登记，仅未登记的缺失类判为回归
* **多版本代码去重**：1.20.1 与 1.21.11 中逻辑相同的实现合并到共享源码集，版本目录只保留 API 差异。已合并物品喷射的模拟与全局渲染、分类首页布局、粒子变形与碰撞外观、自动旁观模式恢复状态五组，两侧各少一份重复实现；相机矩阵、渲染事件注册、图标矩阵与 `GameMode` 读写等差异抽成小适配器留在版本侧。剩余 24 组版本文件的差异已逐条分类为「可共享 8 组、只能部分共享 10 组、必须独立 6 组」，只登记结论、不强行合并渲染管线不同的实现
* **修复流体伪装随机抖动**：玩家伪装或影片回放选择本模组的流体时，水面会随机剧烈抖动一段时间后自行恢复，重新编辑又会复现。原因是每 tick 注入给流体的力没有上限，而扩散与耗散只在渲染帧按墙钟节流推进——回放或编辑期间帧率波动时，注入的能量超过每步耗散，振幅无界累积成「鬼畜」，直到某次重建才回落。现改为在 tick 中以固定步长推进模拟、对单格振幅设上限，并把力注入与帧率解耦，水面恢复稳定；流体的物理交互与外观参数不变
* **构建与初始化**：`build12111` 运行共享测试，Model Morph 测试随 1.20.x 运行。可选模组的注册按前置启用，1.21.11 的 Mixin 自检直接读取打包配置
* **修复 1.21.11 模型拾取**：伪装编辑器恢复普通左键选中骨骼。拾取使用与新版渲染管线匹配的顶点格式和着色器，并按贴图透明度判断命中。
* **修复 1.21.11 Iris 纹理清理异常**：调整 PBR 纹理的清理顺序，避免退出客户端或重载资源时因缓存正在被修改而中断清理。
* **修复同名存档的旁观模式恢复**：新的单人恢复记录按存档目录匹配，避免在另一份同名存档中提前触发恢复。旧格式记录仍可读取。

#### 3.6.8（移除原版辉光 + 描边与设置整理）：
* **移除原版辉光**：删除「原版辉光」开关、叠加层与相关 API，描边只保留纯色 / 渐变外壳与 LabPBR 自发光。旧存档中的 `outline_vanilla_glow` / `overlay_vanilla_glow` 键会被忽略，不影响描边本身
* **静止模型不再反复重建**：外壳缓存键对动画姿态做 1/4096 量化，IK、物理或约束求解产生的亚像素抖动不再触发整壳重建
* **渐变开销**：只有存在有效渐变层时才更新屏幕方向，纯色描边不再做矩阵求逆
* **缓存回退更可控**：外壳构建失败会记录一次日志并回退到立即渲染；深度 pass 按模型与配置精确配对，不再因单个模型错位清空整帧队列
* **设置分类重整**：设置模块由按来源或版本命名的旧分类重排为 7 个功能分类：时间轴与关键帧、姿势与动画、光影、界面与交互、渲染与性能、操控器与建模、导出；39 个可见项与 16 个隐藏持久化项全部重新归属，各分类使用独立图标
* **设置迁移兼容**：旧 `bbspp.json` 会在加载前按选项 id 迁移到新分类并保留备份，已有设置不会回落到默认值
* **设置文案整理**：按术语表统一设置名称与悬浮说明（操控器、锚点、时间轴、光影、面剔除等），开关统一写作“启用 / 禁用”；英文文案同步调整
* **锚点演员列表**：重写锚点关键帧的“选择角色”菜单，沿用影片回放顺序与回放显示名；演员较多时最多显示 10 行并支持滚动，不再超出屏幕
* **肢体选择**：原「忽略选取覆盖」快捷键升级为按住式「肢体选择」（默认 E，按键绑定“变换”分类可改绑）：左键选中实际肢体，右键按骨骼选取覆盖选中；按住期间隐藏操控器、坐标轴、摄像机参考线与 IK 调试层，模型改用原版实体着色器并压在其他模型之前；松开立即恢复，只在 BBS 界面内生效
* **肢体选择关键帧**：动画态编辑器与影片回放面板打开时，按住期间左右键都会直接为目标骨骼新建关键帧——左键给实际肢体，右键给骨骼覆盖指向的骨骼
* **肢体选择拾取**：模板缓冲区统一记录实际肢体，读取拾取结果时再按鼠标键映射骨骼覆盖，避免缓冲区滞后导致选错骨骼；表单编辑器原本右键不拾取，现由预览渲染器接管
* **肢体选择性能**：切换原版着色器时保留 VAO 渲染路径，不再退回逐顶点 CPU 变换，修正按住时的掉帧
* **肢体选择教程**：按键绑定页悬停「肢体选择」显示分步用法说明，中英文各一份
* **动作页列表高度**：动作页「动作」「动画」两个列表底边新增拖拽带（6px，骑在底边、不抢下层点击），拖动改高度、双击还原，高度写入布局配置并跨界面保留

#### 3.6.7（描边渐变 + 应用到子骨骼）：
* **描边渐变**：描边颜色行新增模式图标，可在纯色与渐变之间切换。切换为渐变时两端沿用当前颜色，画面不会立即变化；原色块的位置改为方向按钮，用于切换上下 / 左右渐变，颜色行下方同时展开渐变编辑条
* **渐变编辑条**：左侧色块修改当前选中色标的颜色，拖动色标调整位置，右键渐变条可新增或删除色标（至少保留一个）。色标位置与颜色写入骨骼姿势数据，并随关键帧保存
* **渐变投影**：主色渐变按屏幕方向投影（上下沿屏幕竖直轴、左右沿屏幕水平轴，范围取模型包围盒的跨度），任何角度看描边都是一整条渐变，不会再出现整圈纯色，相机转动时外壳按新方向重新烘焙；逐面渐变仍按每个面的水平 / 垂直双轴投影——前、后、左、右面为 X / Y，上、下面为 X / Z，模型旋转后仍按该面自身的方向渐变
* **渐变优先级**：面渐变 > 面纯色 > 主渐变 > 主纯色；某个面单独设置了渐变或颜色时，该面不再使用主色渐变
* **应用到子骨骼**：姿势编辑器颜色行新增「应用到子骨骼」图标（渐变模式下显示），把当前渐变复制给全部子骨骼并清除子骨骼残留的渐变
* **叠加与逐面联动**：叠加描边同样支持渐变；「全部跟随主颜色」会同时清除六个面的渐变；自动展开判据包含渐变设置
* **老存档兼容**：未写入渐变键的旧存档按纯色处理
* **多版本**：1.20.1 / 1.20.4 的 LabPBR 自发光改用 64×1 渐变条纹理采样，逐像素计算发光强度；1.21.11 通过顶点色实现渐变（屏幕方向投影只作用于 1.20.x，1.21.11 仍按模型空间取样）
* **全部应用到子集**：描边栏「启用描边」上方新增独占一行的文字按钮，一次把两层描边的全部参数（颜色、渐变、宽度、发光、原版辉光、面剔除、逐面颜色与渐变）复制给该骨骼的所有子骨骼，不必再逐项右键
* **颜色行排版**：纯色模式下隐藏「应用到子骨骼」图标（改由右键色块触发）；渐变模式的方向按钮贴在色块左缘，三个图标因此相邻；渐变编辑条与左侧色标色块之间加大间距，不再融成一整条
* **右键菜单精简**：「全部跟随主颜色」的右键只保留「应用到子骨骼」，移除与原按钮重复的「重置本骨骼」
* **光影下纯色描边发白修复**：纯色描边生成的 1×1 自发光纹理此前按单通道（灰度）写出，色相与发光强度一并丢失，导致开启光影（Iris）时描边被自发光 pass 冲成近白色、必须打开「原版辉光」才显色。改为按 RGBA 写出后，纯色描边在光影下直接呈现设定颜色，发光强度照常生效

#### 3.6.6（描边叠加与逐面颜色、1.21.11 渲染适配、Bedrock 步阶帧修正）：
* **发光改为 LabPBR 自发光**：原先「发光」只是一个开关，`1`–`255` 的取值不影响画面。现在它直接写入 LabPBR 自发光通道的 alpha：`0` 为不发光，`1`–`254` 线性增强，`255` 按规范保留为「不发光」而不再使用。该通道只由声明了 `normals` / `specular` 采样器的光影包读取，未启用光影时描边保持纯色外壳
* **原版辉光独立为开关**：旧版「整圈更亮」的效果拆分为独立的「原版辉光」开关，位于「发光」下方，不依赖光影，与大部分光影不兼容
* **描边分层重构**：纯色外壳始终包含全部描边骨骼，发光与原版辉光改为在其之上的叠加层，两层互不影响，开启任一层都不会改变描边轮廓或基础颜色；外壳几何缓存相应合并为单一缓冲，减少重复构建
* **面剔除开关**：新增逐骨骼「面剔除」选项，默认开启；关闭后描边壳双侧绘制，薄片与贴片类方块在任何角度都能看见描边，代价是顶点数翻倍
* **塌陷方块不再产生描边**：Blockbench 常写入的零厚度平面与线条在描边壳向外扩张后会重新获得面积，此前会在画面上留下一条细边；现在按真实包围盒判定平坦轴，只绘制确实存在面积的面
* **老存档兼容**：旧存档中「发光」为开启状态的骨骼会自动回填「原版辉光」，升级前后观感一致；关闭状态的骨骼不会凭空出现辉光
* **步阶帧判定**：此前只要关键帧带 `pre` 即判定为步阶帧，而 Blockbench 对含前值的关键帧一律写入 `pre` 与 `post`（平滑关键帧两者相同），导致平滑动画被当作步阶播放。现按动画文件中的插值声明判定：本帧 `pre` 与 `post` 不同，或上一帧声明 `easing` 为 `step`，才视为步阶帧
* **步阶帧插值**：步阶帧使用 BBS 内置的步阶插值（`CONST`），方块模型动画按段内后一帧取插值时即可正确保持前值并在该帧瞬跳
* **步阶帧之后的动画段**：动画转姿势关键帧时，步阶帧的插值曾被一并写入姿势关键帧，使离开该帧的一段同样被保持。现改为沿用下一帧的插值，离开步阶帧的段落恢复平滑
* **姿态烘焙**：同样保留步阶帧，且不会多保持一段
* 以上修正仅影响含步阶帧的动画，纯 catmullrom 与线性动画的播放不受影响
* **叠加描边**：描边栏新增「叠加描边」开关，开启后在该骨骼当前描边之外再套一层，并在下方展开对等的「描边叠加」栏。两层各有独立的颜色、宽度、发光、原版辉光、面剔除与逐面颜色，参数全部写入骨骼姿势数据并随关键帧插值；第二层宽度表示向外再扩出多少，绘制时按宽度降序，里层压在宽层之上形成双环
* **逐面颜色**：每层新增可折叠的「高级选项」子栏，前 / 右 / 后 / 左 / 上 / 下六个面可单独取色，未设置的面跟随该层主色；「全部跟随主颜色」按钮可一次复原。面颜色按整块取最近关键帧，不做插值
* **1.21.11 渲染适配**：纹理变换、纹理调色 / 白化与附魔光效在 1.21.11 上补齐渲染实现——纹理变换改在 CPU 顶点写出时应用，调色 / 白化与光效各自接管模型提交，不再只改 UI 不生效
* **1.21.11 拾取修复**：修复面板与模型编辑器预览中点不中骨骼、点中的是 gizmo 手柄以及深度缓冲未清空导致的整片未命中
* **撤销后轨道列表滚动保持**：撤销只回退数据，不再把左侧回放列表滚回顶部，也不再把关键帧编辑器的轨道列表压回最上方
* **构建产物分离**：1.21.11 专属的 mixin 配置与着色器不再进入 1.20.1 / 1.20.4 的 jar，避免低版本因类不存在而在启动阶段崩溃

#### 3.6.5（模型描边逐骨骼化 + 姿势面板收纳）：
* **描边改为逐骨骼设置**：描边参数由模型 `config.json` 迁移到骨骼姿势数据，与 PBR、附魔光效保持一致；每根骨骼可独立开启描边并设置颜色、宽度、辉光与不描边块尺寸，参数支持关键帧插值。旧 config 中的描边键不再读取，已有工程需在姿势编辑器中重新开启
* **姿势编辑器布局调整**：PBR 栏下方新增可折叠的「描边」栏；附魔光效改为独立的「附魔光效」栏，位于描边栏下方。描边与光效参数均支持右键「应用到子骨骼」
* **附魔光效重构**：附魔光效栏支持颜色、透明度、流动速度与亮度；参数写入骨骼姿势数据，支持关键帧插值
* **Iris 光影兼容**：1.20.1 / 1.20.4 在光影包接管世界绘制时，使用原版 glint 程序对同一组 VAO 二次绘制；内置 shader 与光影路径共用相位，开关光影时流速一致。未提供 `gbuffers_armor_glint` 的光影包会回退到 `gbuffers_textured`
* **设置整理**：移除 BBS++ 设置页中的附魔光效分类与开关，附魔光效栏始终显示；光效数据与渲染逻辑保持不变
* **影片轨道属性面板**：影片编辑器中，肢体轨道关键帧的属性面板在材质栏下方新增 PBR、描边、附魔光效三个折叠栏，可直接按骨骼调整；姿势轨道关键帧面板中的同类栏作用于当前选中的骨骼
* **描边渲染适配**：外壳几何按每根骨骼的描边参数构建与缓存，骨骼之间互不影响；没有开启描边的模型会跳过描边几何构建与深度补写，避免额外开销
* **描边开关同步**：重新打开姿势编辑器后，描边、附魔光效与 PBR 控件会跟随自动选中的骨骼刷新，纹理变换栏的默认展开状态同步更新；模型已渲染描边但开关显示关闭的问题不再出现

#### 3.6.2（穿透粒子导致编辑器预览黑屏修复）：
* **问题现象**：场景中存在开启了「穿透渲染」（忽略深度，X-Ray）的 AAA 粒子时，打开模型方块页、影片页等编辑器预览界面，3D 视口会整片纯黑（只显示侧栏 UI 与 gizmo），或反过来被整张方块图集铺满，且日志中没有任何报错
* **根本原因**：穿透渲染需要在主渲染流程之外额外再绘制一遍粒子。Effekseer 的 C++ 底层会绕过 Minecraft 的 `RenderSystem` 直接调用 `glActiveTexture` / `glBindTexture` 改写真实纹理绑定，`RenderSystem` 的贴图缓存因此与 GL 实际状态脱节；后续绘制认为贴图已绑定而跳过重绑，采样到空贴图或方块图集，整片视口随之变黑或铺满图集
* **状态还原**：穿透渲染段改为 `try/finally` 结构，深度范围、深度函数、深度写入、深度测试、帧缓冲绑定与视口在退出时按进入前的原值无条件还原，不再受绘制中途异常影响
* **纹理缓存校正**：退出时把 0~7 号纹理单元按 GL 的真实绑定重新经 `RenderSystem` 绑定一次（绑定值不变，仅校正缓存），既清掉 Effekseer 留下的状态，也不再出现"清空绑定导致全黑、回滚绑定导致图集铺屏"的问题
* **兼容性**：修复位于穿透渲染的独立绘制段，不影响 AAA 粒子本身的显示、穿透效果与透明排序
